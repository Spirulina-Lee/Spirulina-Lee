你好 👋 我学电气工程，本科在重庆邮电大学和北亚利桑那大学，现在在华盛顿大学读研。

这里大多是课程作业和自己做的小项目，从单片机、数字电路到 Web 看板和 LLM Agent。

### 做过的东西

- **[BMS-Alarm-Capstone](https://github.com/Spirulina-Lee/BMS-Alarm-Capstone)**：本科毕业设计，一个帮校园楼宇管理系统过滤无效报警的看板。
- **[llm-agents-ee500d](https://github.com/Spirulina-Lee/llm-agents-ee500d)**：一个会查天气、找附近景点的 LLM Agent。
- **[MathModeling](https://github.com/Spirulina-Lee/MathModeling)**：两次数学建模比赛，一次研究苹果树树冠长成什么形状最能晒到太阳，一次研究工厂什么时候该检测零件，都拿了奖。
- **[CompEng-Basics](https://github.com/Spirulina-Lee/CompEng-Basics)** 和 **[MSP430 实验](https://github.com/Spirulina-Lee/Microprocessor-Labs-MSP430-EE215)**：用硬件描述语言写数字电路，以及在单片机上写底层代码。
